OpenSquilla 架构调研（9.0）

八框架 Skill 进化产品化最强：每轮 RRF 推荐 + proposals 四关 + E2E 晋升

显式 Agent FSM 分阶段 harness；SkillSpec + 6 层优先级；每轮 filter_skills → 注入；proposals/ 多关 accept 写入 MANAGED。

1. 架构

分阶段 harness：Gateway → TurnRunner → Pipeline(filter→inject) → FSM。6 层优先级：EXTRA → BUNDLED → MANAGED → PERSONAL → PROJECT → WORKSPACE。

2. Skill 运行时

每轮 HybridRetriever（词法+语义 RRF top-5）；compact/full 渐进披露；meta_invoke 跑 DAG；collect_invoked_skills 遥测。

3. Skill 生命周期

hub 安装 → auto_propose/Dream → gates.json 四关 → accept→MANAGED；skills-lock SHA256。生命周期 12/13。

4. Skill 进化

决策日志/Dream → proposals/ → runtime_e2e 对照 → accept。eval_prompts 回归 + meta vs baseline A/B。

5. 多 Agent Skill

MetaOrchestrator DAG（skill_exec/agent/tool_call）；子 agent one-shot，无 skill preload 列表。

6. Skill 治理

policy chain 30+ 内置规则；gates.json；hub quarantine；requires_tools 门控。

7. Harness 集成

Skill 是 pipeline 阶段而非外挂：filter_skills 在 LLM 看到 catalog 前确定性门控。

8. RL 就绪度

PipelineStepRecord + decision_log skills_invoked；Claw-R1 兼容 step 级记录最强之一。

9. TaiChu 可借鉴

TaiChu 借：proposals+gates、RRF+always pin、invoked 遥测、runtime_e2e、inject_compact。

10. TaiChu 落地

P1 proposals 目录+gates；P1 Toollery RRF；P2 interaction_log；P3 MetaSkill。

11. 不应借鉴

勿搬 6000 行 agent 单体；勿无 gate 自动 accept。

12. 评分

总分 9.0：Runtime/Evolution 双 9；RL 6（轨迹强、无训练器）。
