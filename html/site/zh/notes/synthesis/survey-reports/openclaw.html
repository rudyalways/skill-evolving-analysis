OpenClaw 架构调研（8.0）

6 源 merge + skill-workshop 进化 + per-agent skillFilter

多源 SKILL.md merge；metadata XML catalog；read tool 懒加载 body；workshop proposals。

1. 架构

6 源优先级 merge；chokidar watcher；session snapshot。

2. Skill 运行时

150 skill / 18K 上限；compact XML；per-agent skillFilter 白名单。

3. Skill 生命周期

workshop agent_end → reviewer → proposals → scanner → append/replace。

4. Skill 进化

LLM reviewer + regex；auto/manual 策略；trajectory 元数据。

5. 多 Agent Skill

subagent 缩减 system prompt；skillFilter 继承。

6. Skill 治理

skill-scanner quarantine；workshop pending。

7. Harness 集成

Gateway + agent loop；skill-workshop 与 compact 并行。

8. RL 就绪度

openclaw-trajectory JSONL；OpenClaw-RL 离线 RL 层。

9. TaiChu 可借鉴

借 6 源 precedence、workshop 闭环、trajectory schema。

10. TaiChu 落地

P1 workshop-style proposals；P2 skillFilter 子 agent。

11. 不应借鉴

勿全盘 marketplace 信任模型。

12. 评分

总分 8.0：Lifecycle 9/13；Compact-skill 弱。
