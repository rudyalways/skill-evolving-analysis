Hermes Agent 架构调研（8.1）

运行时 Skill CRUD + 后台自进化最强，但缺 proposal 队列与 read-before-write 硬门禁

~/.hermes/skills SKILL.md；metadata index + skill_view 渐进披露；skill_manage 全 CRUD + 后台 review。

1. 架构

CLI/Gateway 一体；skills 目录扫描；bundled manifest hash 同步。

2. Skill 运行时

session 冻结 index；skill_view 按需 body；slash 与 --skills preload。

3. Skill 生命周期

agent skill_manage create/patch/delete；skills_guard 扫描；无 formal proposal store。

4. Skill 进化

nudge + _spawn_background_review → 直接 patch；Atropos RL 扩展。

5. 多 Agent Skill

delegate_task 隔离 context；无 skill preload 参数。

6. Skill 治理

skills_guard 写后扫描；issue 风险：无 critical-skill lock。

7. Harness 集成

TurnRunner + toolsets；skill 为一等工具。

8. RL 就绪度

JSONL + session DB；Atropos 轨迹；RL tool 在线训练。

9. TaiChu 可借鉴

借 CRUD 面与 review 思路；TaiChu 需加 gate 而非直接生产 patch。

10. TaiChu 落地

P1 read-before-write gate；P2 skill_manage 候选流。

11. 不应借鉴

勿无 gate 直接生产 patch；勿忽略 hallucinated deletion 风险。

12. 评分

总分 8.1：Evolution 9；Governance 5 拉低。
