OpenSquilla 架构调研（9.0）

八框架 Skill 进化产品化最强：每轮 RRF 推荐 + proposals 四关 + E2E 晋升
显式 Agent FSM 分阶段 harness；SkillSpec + 6 层优先级；每轮 filter_skills → 注入；proposals/ 多关 accept 写入 MANAGED。

Local: /Users/maybewu/Documents/Projects/oss/opensquilla · Upstream: opensquilla/opensquilla · Matrix: agent-skill-architecture-survey-matrix.md · Detail card: repos/opensquilla.md

1. Architecture

中文 分阶段 harness：Gateway → TurnRunner → Pipeline(filter→inject) → FSM。6 层优先级：EXTRA → BUNDLED → MANAGED → PERSONAL → PROJECT → WORKSPACE。

OpenSquilla is a staged harness around an explicit Agent FSM (IDLE→THINKING→TOOL_CALLING→DONE). Skills are first-class SkillSpec objects loaded through a 6-layer precedence system, filtered every turn by pipeline step filter_skills, injected via SkillInjector, and evolved through a proposals directory with multi-gate acceptance.

Gateway → TurnRunnerHarness → Pipeline (filter_skills → inject) → Agent FSM
                                              ↓
                                    proposals/ → accept → MANAGED
