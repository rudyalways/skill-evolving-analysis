Hermes Agent 架构调研（8.1）

运行时 Skill CRUD + 后台自进化最强，但缺 proposal 队列与 read-before-write 硬门禁
~/.hermes/skills SKILL.md；metadata index + skill_view 渐进披露；skill_manage 全 CRUD + 后台 review。

Local: /Users/maybewu/Documents/Projects/oss/hermes-agent
Upstream: NousResearch/hermes-agent
Matrix: agent-skill-architecture-survey-matrix.md

1. Architecture

中文 CLI/Gateway 一体；skills 目录扫描；bundled manifest hash 同步。

Hermes is a Python monolith (run_agent.py 9.8k lines) combining: OpenAI tool-calling agent loop, Gateway, 40+ tools, frozen MEMORY prefix cache, and Atropos RL environment. Skills follow agentskills.io-compatible SKILL.md under `/.hermes/skills/, with **progressive disclosure** (skills_list→skill_view) and **agent-writable** procedural memory via skill_manage`.

AIAgent loop → tools (skills_list, skill_view, skill_manage)
                    ↓ post-turn
            _spawn_background_review → quiet agent → patch/create skill
                    ↓
            ~/.hermes/skills/  (+ skills_guard scan)
