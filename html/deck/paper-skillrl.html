Cold-Start SFT

Before RL begins, supervised fine-tuning teaches the agent how to use skills from SkillBank. Without this, the policy cannot leverage retrieved heuristics during early GRPO rollouts.

What's Novel vs Standard

  • GRPO: not novel — standard policy optimization
  • SkillBank + recursive evolution: novel wrapper around GRPO
  • Failure lessons: failures feed SkillBank, not dropped

Before — Episodic Independent Tasks

  • Task 1 → trajectory → forget
  • Task 2 → trajectory → forget
  • Task 3 → trajectory → forget
  • No cross-task knowledge transfer
  • Memory grows unbounded with raw logs

After — Reusable Skill Library

  • Trajectories → distilled skills
  • SkillBank grows smarter with policy
  • Better policy → better trajectories → better skills
  • Hierarchical retrieval generalizes
  • Recursive validation prunes weak areas

Key Takeaways

  • Compress experience: 10–20× token reduction vs raw trajectories
  • Learn from failure: failure lessons in SkillBank, not discarded
  • Co-evolve: policy and SkillBank improve together recursively
  • Hierarchical retrieval: general + task-specific heuristics on demand
  • Algorithm-agnostic data: pairs with Claw-R1 step streams as input fuel
"…a framework that bridges the gap between raw experience and policy improvement through automatic skill discovery and recursive evolution." — Abstract, arXiv:2602.08234
Open questions & limitations
  • SkillBank growth: pruning strategy as library scales — when to retire low-success skills?
  • Retrieval sensitivity: threshold δ and Top-K hyperparameters affect which skills reach the policy
  • Teacher quality: distillation quality depends on teacher LLM; bad skills propagate
  • Claw-R1 integration: can step-level Data Pool traces feed SkillRL trajectory builder directly?
  • Validation cost: recursive epoch frequency vs benchmark evaluation overhead
  • Retrieval optimization: skill selection is itself an optimization problem alongside GRPO
