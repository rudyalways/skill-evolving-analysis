端到端

  1. Master Agent（ReAct）查 Skill Bank 或 Skill Creator 合成包
  2. SKILL.md + scripts/ + tests/ + resources/
  3. Executor 沙箱 → Evaluator 跑 tests

应用要点

  • M1： 文件级渐进加载、目录组织、有 tests
