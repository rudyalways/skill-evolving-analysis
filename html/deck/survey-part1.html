SkillRL — Algorithm Layer

arxiv:2602.08234 GRPO SkillBank

  • Focus: How the policy learns from experience
  • Stores: Compact reusable skills (not raw trajectories)
  • Pipeline: Rollouts → Teacher LLM distillation → SkillBank → GRPO → co-evolve
  • Novelty: Recursive SkillBank + failure lessons, not RL algo itself
SkillBank quote

Claw-R1 — Infrastructure Layer

arxiv:2606.09138 Gateway Data Pool

  • Focus: Step-level data middleware — not a new RL algorithm
  • Stores: Independent, queryable step records
  • Pipeline: Agent → Gateway → Step records → Data Pool → RL Trainer
  • Why step-level: 20-step traj, 19 correct, 1 wrong — train only the wrong step
Step query example
These two papers target different layers of the agent RL stack. They are complementary, not competing. Claw-R1 provides a high-quality, queryable stream of step-level interaction data; SkillRL consumes trajectories, distills reusable skills, updates policy with GRPO, and recursively evolves the SkillBank. — comparison.md · One manages data lifecycle; the other improves learning algorithm

Without Stack

Episodic agents · raw trajectory dumps · long noisy context · no failure mining · no step curation
