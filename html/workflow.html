Research workflow研究工作流

How to handle incoming data without losing track如何处理新数据而不迷失方向

1. Receive → inbox

Drop anything new into data/inbox/ — PDFs, JSON exports, repo clones, screenshots, API responses. Don't organize yet; just capture.

2. Triage → raw

Run the ingest script to copy into the correct data/raw/ bucket with a date prefix:

./scripts/ingest.sh data/inbox/skillrl.pdf papers
./scripts/ingest.sh data/inbox/run-log.jsonl experiments
./scripts/ingest.sh data/inbox/openclaw-rl/ repos

Raw files are immutable — never edit originals.

3. Document → note

Copy a template from templates/ and fill in metadata:

TemplateUse when
paper-note.mdReading a new paper
data-entry.mdFiling raw data with provenance
experiment-log.mdRunning or logging experiments
daily-log.mdEnd-of-day research journal

4. Process → derived artifacts

Extract structured data into data/processed/:

  • extractions/ — parsed sections, JSON schemas, code snippets
  • tables/ — benchmark numbers, comparison matrices
  • embeddings/ — vector indexes for semantic search

5. Synthesize → topics & notes

Update topic overviews under topics/ and write cross-cutting analysis in notes/synthesis/.

6. Catalog → INDEX.md

Every artifact gets a row in INDEX.md. This is the single source of truth for "what do we have?"

Status lifecycle

inbox  →  raw  →  processed  →  (linked in notes/topics)
                              ↘
                           archived  (when superseded)

Daily rhythm

  1. Clear data/inbox/ — triage everything
  2. Update INDEX.md
  3. Write notes/daily/YYYY-MM-DD.md
  4. Refresh topic overviews if new insights emerged
